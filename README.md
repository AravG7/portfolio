## 🚀 Getting Started

1. **Clone & Install:**
```bash
git clone https://github.com/AravG7/portfolio.git
cd portfolio
npm install

```


2. **Run Development:**
```bash
npm run dev

```


3. **Build for Production:**
```bash
npm run build

```
